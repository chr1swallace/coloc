# credible.sets

Get credible sets from finemapping results

## Usage

``` r
credible.sets(dataset, credible.size = 0.95)
```

## Arguments

- dataset:

  data.frame output of
  [`finemap.abf()`](https://chr1swallace.github.io/coloc/reference/finemap.abf.md)

- credible.size:

  threshold of the credible set (Default: 0.95)

## Value

SNP ids of the credible set
