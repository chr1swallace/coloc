## Bayesian enumeration of hypotheses

Two trait colocalisation and single trait fine mapping under single
causal variant assumptions

- [`coloc.abf()`](https://chr1swallace.github.io/coloc/reference/coloc.abf.md)
  : Fully Bayesian colocalisation analysis using Bayes Factors
- [`finemap.abf()`](https://chr1swallace.github.io/coloc/reference/finemap.abf.md)
  : Bayesian finemapping analysis

## Sensitivity analysis

Check how robust inference is to changing prior parameter values

- [`sensitivity()`](https://chr1swallace.github.io/coloc/reference/sensitivity.md)
  : Prior sensitivity for coloc

## Relaxing the single variant assumption

use conditioning or masking to account for multiple independent causal
variants per trait

- [`coloc.susie()`](https://chr1swallace.github.io/coloc/reference/coloc.susie.md)
  : run coloc using susie to detect separate signals
- [`runsusie()`](https://chr1swallace.github.io/coloc/reference/runsusie.md)
  : Run susie on a single coloc-structured dataset

## Colocalisation of credible sets

Approximate coloc using fine-mapped credible sets

- [`coloc_pip()`](https://chr1swallace.github.io/coloc/reference/coloc_pip.md)
  : An approximation to coloc using only information from fine-mapped
  credible sets.
- [`clPP_to_coloc()`](https://chr1swallace.github.io/coloc/reference/clPP_to_coloc.md)
  : convert CLPP to coloc posteriors

## Querying Open Targets and eQTL Catalogue

Find public credible sets overlapping your own, and colocalise against
them

- [`query_ot()`](https://chr1swallace.github.io/coloc/reference/query_ot.md)
  : query Open Targets credible sets
- [`query_eqtl_cat()`](https://chr1swallace.github.io/coloc/reference/query_eqtl_cat.md)
  : query eQTL catalogue credible sets
- [`coloc_query()`](https://chr1swallace.github.io/coloc/reference/coloc_query.md)
  : Colocalisation of an index credible set and a list of credible sets
  generated by query_ot() or query_eqtl_cat()
- [`query_ot_many()`](https://chr1swallace.github.io/coloc/reference/query_ot_many.md)
  [`query_eqtl_cat_many()`](https://chr1swallace.github.io/coloc/reference/query_ot_many.md)
  : Query Open Targets or eQTL Catalogue for many credible sets
- [`coloc_query_many()`](https://chr1swallace.github.io/coloc/reference/coloc_query_many.md)
  : Colocalise many credible sets with their query results
- [`ot_fetch()`](https://chr1swallace.github.io/coloc/reference/ot_fetch.md)
  : Download a complete local copy of the Open Targets credible sets
- [`eqtl_cat_fetch()`](https://chr1swallace.github.io/coloc/reference/eqtl_cat_fetch.md)
  : Download eQTL Catalogue credible sets
- [`ensembl_to_symbol()`](https://chr1swallace.github.io/coloc/reference/ensembl_to_symbol.md)
  : Translate Ensembl gene ids to HGNC gene symbols
- [`coloc-options`](https://chr1swallace.github.io/coloc/reference/coloc-options.md)
  [`coloc.cache_dir`](https://chr1swallace.github.io/coloc/reference/coloc-options.md)
  [`coloc.max_temp_download`](https://chr1swallace.github.io/coloc/reference/coloc-options.md)
  : Package options
